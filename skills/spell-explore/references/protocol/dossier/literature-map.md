## how to use it
- M11 literature triangulation: record theorem, source, hypotheses and exactly what it leaves open; check whether the claim you want to prove — or its negation — is already known. this is what distinguishes "open" from "impossible".
- read surveys before primary sources; follow citation chains in both directions; adapt proofs, never cite them unread.
- R9: before asserting a statement is false or hopeless, check the literature and search for a counterexample (M10, M11).
- separate "known" from "believed": entries that cite external results carry the source; entries that are the worker's own reasoning are marked as such.
- precise citations: the hygiene linter's layer 1 requires every citation to resolve to a real source with a locator, so this map stores locators, not vague pointers.
- relevance to the goal feeds the Producer's goal-frontier score for every pool idea — term overlap with the locked goal statement, the number of [Formalized] or [Hired] premises it can cite on the report/ITG path toward the goal, whether it would hire new assumptions, and its provenance — so each entry states why the source matters for the locked goal.
- entries must use the locked notation (one fixed block, kept with the index; all entries must use it), and every entry ends with a concrete next step.

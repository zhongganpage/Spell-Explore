# reformulations.md — reformulations & connections

numbered forms, each with "useful because…" and a date. this file is the split-out reformulations-and-connections section of the dossier (see the ~30 KB split rule and the Knowledge State navigation index in ./index.md). every reformulation is recorded, even ones that go nowhere (rule R4): each is search fuel and future insight. every new form is a new set of literature search terms (stuck-ladder step 3).

## how to use it
- M5 reformulate: translate the problem — fixed-point, optimization, variational, combinatorial, probabilistic, graph-theoretic, generating-function; change variables, normalize, take the dual, complement, contrapositive, a transform. every new form is new search fuel and a new way to see the obstruction.
- M11 literature triangulation: for every reformulation, search its terminology; find the nearest known theorem and read its proof fully (adapted, not cited); record theorem, source, hypotheses and exactly what it leaves open in literature-map.md; follow citation chains in both directions; read surveys before primary sources.
- entries must use the locked notation (one fixed block, kept with the index; all entries must use it), and every entry ends with a concrete next step.

## format — numbered forms

```
### Form <n> — <short name> — <date>
useful because: <why this form helps: what it exposes, what it connects to>
statement:      <the problem in this form, in the locked notation>
connections:    <what it connects to: other forms, known theorems, the obstruction>
searched:       <terminology searched; nearest known theorem, if any>
```
